# PoplarPheno Collector - 杨树表型数据采集App

## 项目简介

PoplarPheno Collector 是一款专为杨树（Poplar）表型数据采集设计的Android应用程序。该App用于辅助科研人员进行杨树表型性状的野外数据采集工作。

## 版本信息

- **当前版本**: v9
- **APK文件**: PoplarPheno-Collector-v9.apk
- **开发状态**: ✅ 开发完成
